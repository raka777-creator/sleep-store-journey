# Website to store journey: concept prototype

A clickable prototype of the website to store journey: sleep profile quiz, one store action on the product page, try before you pay in the cart, prefilled booking, visit pass, in store screens, and the WhatsApp follow up.

Concept prototype by Rakshit Agnihotri. It is not an official site. Prices, stores and the QR code are sample data. Payment is not part of the prototype.

Static site, no build step. Open index.html, or serve the folder with any static server.
Use the Guide button at the top right to jump to any step.
